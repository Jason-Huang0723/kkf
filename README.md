# 慈幼山友方案庫

台大慈幼山友歷屆方案（早期、第 1–37 期）的查詢網站。

**網站：** 開啟 GitHub Pages 後，網址為 `https://<帳號>.github.io/kkf-plans/`

## 內容

- 依九類瀏覽方案：自然科學、運動競賽、社會與文化、藝術與表演、健康與生活技能、闖關與解謎、閱讀表達與品格、信望愛、其他（營包、早操、破冰、營歌、晚會、營手冊、校外教學、午休與自由活動）
- 每個方案有期別、服別、時長與人力、目標、團本建議、標籤，以及方案紙和方案資料夾的連結
- 方案紙與資料夾連結指向社團雲端，需要有雲端權限才能開啟

## 幫忙檢查

目前請社員協助檢查：

1. 方案有沒有放錯分類
2. 方案名、目標、團本建議有沒有錯字或內容錯誤
3. 方案紙、資料夾連結能不能打開、有沒有連錯
4. 有沒有漏掉的方案

發現問題請到本 repo 的 **Issues** 開一則，寫上「期別＋方案名」和問題；或直接告訴負責人。
